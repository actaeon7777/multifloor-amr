# 배송 키오스크

Jetson의 가로 터치 화면에서 사용하는 배송 화면이다. 웹 주소는
`http://127.0.0.1:8080/kiosk`이며, 1920×1280 화면을 Chromium 배율 1.5
(CSS 1280×853)로 표시한다. 서버가 준비되어 있어야 한다.

## 시작·종료

로그인한 데스크톱의 터미널에서 `scripts/kiosk/launch.sh`를 실행한다.
`AMR_WEB_PORT=8080`으로 포트를 지정할 수 있다. 실행기는 웹 응답을 최대 약 2분 기다린 뒤
별도 Chromium 프로필 `~/snap/chromium/common/amr-kiosk`로 연다.
`curl`, `flock`, `gsettings`, `xwininfo`, Python 3, libX11, Snap Chromium이 필요하다.
전체화면 요청은 창이 1920×1280이 될 때까지 0.5초 간격으로 최대 1분 반복한다.

종료는 키보드 `Alt+F4`, 또는 실행한 터미널에서 `Ctrl+C`를 누른다.
실행 중 화면 꺼짐·잠금을 해제하고 정상 종료·종료 신호 처리 때 이전 값을 복원한다.
강제 종료(SIGKILL)·전원 차단은 복원을 실행할 수 없으므로 GNOME 설정을 확인한다.
브라우저 종료는 배송 취소가 아니다. 배송 취소에는 화면의 **정지**를 누른다.

자동 시작은 필요할 때 사용자가 설치한다. 이 작업에서는 설치하지 않는다.

```bash
mkdir -p ~/.config/autostart
cp /home/acus03/amr_ws/scripts/kiosk/amr-kiosk.desktop ~/.config/autostart/
```

다른 checkout에서는 desktop 파일의 `Exec` 절대 경로를 바꾼다.
자동 시작 해제는 `~/.config/autostart/amr-kiosk.desktop`을 삭제한다.

## 화면·배송

- **대기**: 층과 호실 선택 → 배송지 확인 → 출발. 현재 층은 `현재 층`, 비활성 층은 `운행 안 함`으로 표시한다.
- **배송 중**: 출발 버튼을 누르면 즉시 표시하고 약 3초 후 목표를 한 번 전송한다. 대기 중에는 진행률 0, 예상 도착 미표시이며 카운트다운은 없다. 이때 정지는 전송 없이 대기만 취소한다. 전송 후 정지는 진행 중인 배송을 보낸 곳과 관계없이 취소한다(브라우저가 다시 떠도 정지할 수 있게).
- **엘리베이터**: 승강장 이동·호출·탑승·층 이동·하차·호실 도착의 6단계와 경과 시간을 표시한다.
- **도착 / 배송 실패 / 배송 취소**: 이 키오스크가 보낸 호실 배송의 결과. `수령 확인` 또는 `확인`을 누르고 서버가 승인할 때까지 유지한다. 같은 탭 새로고침에도 배송 요청 ID를 기억한다.
- **준비 중**: 위치·층·주행 준비 확인 전에는 호실 선택이 잠긴다.
- **수동 조작 / 비상 정지**: 배송 화면보다 우선 표시한다.
- **연결 대기**: 조회 실패 또는 약 3초 이상 된 상태에서는 마지막 화면 위에 표시하고 새 명령을 막는다. 미전송 출발 대기는 취소하며 자동 재출발하지 않는다.

진행률은 유효한 거리 피드백을 받은 첫 3초의 최대 남은 거리 대비 감소량이며 뒤로 줄지 않는다. 초기 0.05 m 이하 값은 무시한다. 예상 도착은 최근 약 10초의
거리 감소 속도로 추정하며 데이터가 부족하면 0.3 m/s를 사용한다. 배터리는 신선한 BMS 잔량을 우선 사용하고, 없으면 기존 대시보드의 전압 기준으로
추정한다. 유효한 전원 데이터가 없으면 숨긴다. 지도·호실 좌표와 다른 층의 지도 버전은 `/api/floors`에서 가져온다. 현재 층 명령에는 `/api/kiosk/state`의 라이브 지도 버전을 사용한다.

## 관리 모드

상단 ⚙를 누른다. PIN은 웹 UI를 띄우는 터미널에서 `export AMR_KIOSK_PIN=<숫자>`로 설정한다.
`kiosk_pin:=` launch 인자도 받지만 명령줄(`ps`)에 PIN이 그대로 보이므로 쓰지 않는다. PIN이 있으면 숫자 키패드로 잠금을 해제한다. 미설정 시 바로 열리고
`PIN 잠금 해제됨 (시험 운영)`을 표시한다.

현재 층 지도에서 위치를 누르고 방향으로 끈 뒤 `적용`을 누른다. `마지막 위치로 시작`에는
현재 층 이름·저장 시각이 표시되며 해당 `적용`으로 현재 지도의 저장 위치를 전송한다. `현재 층 변경`은 실제 층 정보가 다를 때 사용한다.
주행·요청 처리 중에는 위치·층 변경 버튼이 잠긴다.

토큰은 메모리에만 보관한다. `관리 모드 종료`, 5분 입력 없음, 토큰 유효기간 만료 또는
관리 요청의 403 오류에서 관리 모드를 종료한다. 서버 오류는 화면에 그대로 표시한다.
